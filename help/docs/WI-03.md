# WI-03 · Measure the correction and build the candidate

**Purpose:** move the whole misplaced piece of map back into place as one rigid block, with its stations, paths, feature lines, areas and bins.

**You need:** the sample ranges from [[WI-02]]: one range driven inside the misplaced piece, one driven where the map is right.

## A. Measure

1. **Map** = the map with the misplaced piece. **Second map** = a map whose reference part is right. If the same map is right in its other part, leave Second map empty.
2. In section 3 type the **Piece samples**, for example `40-262`, and the **Reference samples**, for example `172-372`.
3. In **Show move for stations** type a few station names at the far ends of the piece.
4. Press **Measure turn**. It measures three times and takes the middle value.

Read the result:

| Line | What to check |
|---|---|
| `piece fit rms`, `reference fit rms` | Both about 0.1 m. Above 0.15 m the range is not one rigid piece: narrow it. |
| `turn 2.07 deg, spread +-0.17` | The correction and how sure it is. A spread above 0.3 degrees means the ranges are too short. |
| `how far this moves stations` | Is it plausible? It should match the size of the jump at the seam. |

The values `th`, `tx`, `ty` are filled into section 4 for you.

## B. Draw the region

The region decides what moves. Everything inside moves; everything outside stays exactly as it is.

1. Press **Region** above the map. Click the corners around the whole misplaced piece. Double-click to finish.
2. Include the whole piece: every station, path and wall that belongs to it.
3. Cut the route where the correction is smallest. That is near the pivot, the point the turn is about (given in the Measure result). There the path changes by millimetres; far from the pivot it would change by a metre.
4. The region may be much larger than the map on the far side. Corners outside the map are fine.

## C. Build

1. Type a **Candidate name**, for example `SITEMAP_v6`. It becomes the file name and the map name inside the file.
2. **Anchor map** (optional): an older map whose walls are known to be right. Walls inside the region that also exist there stay where they are. Use it when a rescan was laid over older, correct walls.
3. Press **Build**. The candidate is written to `candidates` and shown in white, with the base map in blue under it.

## D. Read the build report

- `stations moved`, `largest move`: as expected from the measurement?
- `paths crossing the boundary`: these are the paths you cut. Their length changes by the amount shown. It should be a few centimetres. If it is more, the cut is in the wrong place: move it nearer the pivot.
- `CHECKS`: every line must say PASS. [[WI-04]] explains each one.

> If a FAIL says a feature line is close to a path, remove it: **Remove feature lines lying on paths** in section 4, or by hand in [[WI-06]]. A line on a path stops robots with a virtual-laser fault.
