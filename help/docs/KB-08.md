# KB-08 · Words used here

| Word | Meaning |
|---|---|
| **Anchor map** | An older map whose walls are trusted. In a build, walls that also exist there stay in place. |
| **Base map** | The map a candidate is built from. |
| **Candidate** | A map file built by this program. It is on no robot until a person loads it. |
| **Checksum (md5)** | A fingerprint of a file's content. Same checksum = same file. |
| **Confidence** | The robot's own measure (0 to 1) of how well its lasers agree with the map. |
| **Drive / recording** | Position, confidence and laser scans read from a robot about every 0.7 s. |
| **Feature line** | A straight wall segment marked for localisation. |
| **Fit rms** | The typical distance between the laser track and the map after the best single placement. |
| **Jump** | The reported position stepping by 0.5 m or more without the robot moving that far. |
| **Laser track** | The shape of a drive rebuilt from the lasers alone, without a map. |
| **Piece** | A stretch of the drive, or a part of the map, that is rigid in itself. |
| **Pivot** | The point a turn is about; it does not move. |
| **Region** | A polygon drawn on the map. Build and edit tools act on what is inside. |
| **Replay** | Laying a recording's lasers on a map to see where the map disagrees. |
| **Sample** | One reading of a recording. Sample ranges such as `40-262` select part of a drive. |
| **Seam** | Where two pieces of the map meet. Jumps show at seams. |
| **Spread** | How much a repeated measurement varies. |
| **Station** | A named point: LM location mark, AP action point, CP charge point, PP park point. |
| **Step** | How far the map placement moves between neighbouring stretches of a replay. |
| **Stretch** | About 8 m of driving matched to the map as one rigid cloud. |
| **Virtual-laser fault** | The robot stopping for a feature line in its way. |
| **Wall match** | Share of laser points landing on map walls. |
| **Workspace** | One folder for one site: maps, candidates, drives, results, robots. |
