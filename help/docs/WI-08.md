# WI-08 · Work with the AI assistant

**Purpose:** let an AI model run the tools and explain the results in plain language.

The assistant uses exactly the same tools as the buttons. The numbers come from the tools, not from the model, so they are the same whichever model is connected. The model's part is choosing the steps and explaining what the results mean.

## Connect a model (once)

1. Press **Settings**.
2. Fill in one connection:

| Type | Address | Model |
|---|---|---|
| Claude (Anthropic API) | `https://api.anthropic.com` | `claude-opus-5-5` or another Claude model |
| OpenAI-compatible | the server's `/v1` address | the model name on that server |
| Ollama on this PC | `http://127.0.0.1:11434/v1` | a local model that supports tools |

3. Paste the API key (not needed for a model on this PC) and press **Save**. The key is stored encrypted for your Windows user.

## What the model receives

- The text result of each tool, the same text you see at the bottom of the window.
- Never the map file or the laser recordings.
- With a model on this PC, nothing leaves the PC.

## Ask

Open the **Assistant** tab, choose the model, and type. Examples:

- `What is wrong with SITEMAP_live? Use the recording amr06_loop.`
- `Where does the live map make robots jump, and why?`
- `Measure the correction for the east piece and build a candidate called SITEMAP_v6.`
- `Remove the feature line between LM514 and LM515 from SITEMAP_v5 and call it v5c.`
- `Change paths LM517 to LM521 to drive forward.`
- `Are all robots on the same map?`
- `Walk me through WI-04 for the candidate I just built.`

Each tool the model runs is shown as a line you can open to see the request and the result.

## What it can and cannot do

| Can | Cannot |
|---|---|
| Run every tool, read these help pages, build candidates | Load a map on a robot |
| Read status and maps from robots | Change a parameter, relocalise or move a robot |
| Explain a result and propose the next step | See the map picture; it reasons from the text results |

## Check its work

Treat a candidate from the assistant like any other: read the report, replay it yourself ([[WI-04]]), trial it on one robot ([[WI-05]]). Small local models can run the tools but are weaker at working out why a map is wrong; if an answer does not quote tool numbers, ask for them.
