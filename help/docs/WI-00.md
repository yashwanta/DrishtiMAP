# WI-00 · Quick start: how to use DRISHTI Map

**Purpose:** the shortest way from a new install to a first result. Each step names the page with the details.

**You need:** this PC on the robot network, and the name and IP address of one robot.

> The program only reads from robots. It cannot scan a new map and it never puts a map on a robot. Scanning and loading are done in RoboShop.

## 1. Start the program

1. Open `DrishtiMap.exe`. There is nothing to install.
2. On a new PC the lists on the left are empty. That is normal: maps and recordings do not come with the program.

## 2. Add your robots

1. In the left panel, next to **Robots**, press **+**.
2. Type one robot per line: name, a space, IP address. Example: `AMR-03 10.0.0.27`.
3. Press **Add**. Click the robot: you should see its position and the name of its map.

## 3. Get the map the robot is using

1. Point at the robot and press **map**.
2. The map appears under **Maps** and is drawn in the middle.

Only have a file? Use **Import map…** at the top.

## 4. Record a drive

1. Point at the robot and press **rec**.
2. Type a name, for example `amr03_east_loop`, and a time limit, for example `15` minutes. Press **Start recording**.
3. Drive the robot through the place where it has trouble. Start 15 m before the place and end 15 m after it.
4. Click the red **REC** badge at the top to stop. Keep the window open while it records.

The recording appears under **Recordings**.

## 5. Find what is wrong

1. On the **Tools** tab choose the **Recording** and the **Map**.
2. Press **Detect with Recording**. The first run takes a minute or two.
3. Read the marks on the map and the text at the bottom:

| You see | Meaning |
|---|---|
| Red circle, `JUMP 1.36 m` | Robots jump here. |
| Red diamond, `line on path` | A feature line lies in the robot's way. |
| Yellow diamond, `low wall match` | The map and the building do not agree well here. |
| No findings | This map agrees with this drive. |

No recording yet? **Detect (map file only)** still finds lines on paths and broken links, but it cannot find jumps.

## 6. Fix it

| Finding | What to do | Page |
|---|---|---|
| A jump | Find the misplaced piece, measure it, build a corrected map | [[WI-02]], [[WI-03]] |
| A line on a path | **Edit** tab, **Delete line**, click the line, save | [[WI-06]] |
| Something scanned into the route | **Edit** tab, draw a **Box**, **Erase walls**, save | [[WI-06]] |

Every fix is saved as a new file under **Candidates**. Your original map is never changed.

## 7. Check the new map

1. On the **Tools** tab choose the candidate as **Map** and the original as **Second map**.
2. Press **Check Map against Second map**. Every line must say PASS.
3. Press **Replay through Map** with your recording. There must be no jump.

Details: [[WI-04]].

## 8. Put it on the floor

A person loads the candidate in RoboShop, on one test robot first. Record a drive with it and run Detect again. Only then the other robots. Details: [[WI-05]].

## Good to know

- Each button on the Tools, Edit and Assistant tabs has a short example under it.
- **Save text** keeps the result at the bottom in the `results` folder. **Picture** saves the map view.
- To use a recording made on another PC, copy its folder into `drives` in the workspace folder and restart the program.
