# WI-04 · Check and prove a candidate

**Purpose:** show, before a robot sees the file, that the candidate removes the fault and adds no new one.

**You need:** the candidate, the map it was built from, and the recording used in [[WI-02]].

## A. The check list

Set **Map** = the candidate and **Second map** = the map it was built from. Press **Check Map against Second map**. Every build runs this for you and saves it as `NAME.report.txt`.

| Check | Why it matters |
|---|---|
| Same stations, paths, bins, areas, reflectors | Nothing was lost. The fleet still finds every station it knows. |
| Stations that did not move are identical | No direction or property changed by accident. |
| Every path keeps its type, direction, speed | Driving behaviour is unchanged. |
| Moved stations keep their exact spacing | The piece moved as one rigid block. |
| Paths between moved stations keep their length | Same reason. |
| No path closer to a wall than before | A path that moved toward a wall can stop robots or scrape. |
| No station closer to a wall than before | Docking positions keep their clearance. |
| Bins sit on their stations | Load positions moved with their stations. |
| Header covers all walls | RoboShop and the robot can load the file. |
| No feature line closer than 0.45 m to a path | A line on a path raises a virtual-laser fault. |
| Every path ends on an existing station | No broken links. |

Any FAIL must be understood and removed before going on. Objects you changed by hand in the Edit tab are listed as "changed by hand" and are not compared with the base; read that list and confirm each one is what you meant.

## B. Replay

1. Choose the **Recording** and **Map** = the candidate.
2. Press **Replay through Map**. The result must say `JUMPS ... : 0`.
3. Look at every `other step` line. A new step that the old map did not have is a new fault, even below 0.5 m.
4. Press **Fits as one rigid track?**. A good map gives about 0.1 m rms. Use this on a drive without long stops, up to about 120 m; on longer or stop-and-go drives see the note in [[KB-04]].
5. Run the same two buttons on the old map and compare stretch by stretch. Nothing may be worse on the candidate.

## C. A second recording

If you have a recording from another robot or another day through the same area, replay it too. Two recordings agreeing is much stronger than one.

## What this proves, and what it does not

| Proven | Not proven |
|---|---|
| The candidate agrees with the lasers along the recorded route | Places the recording did not drive |
| No station, path or property was lost or changed | The opposite driving direction |
| No path or station moved closer to a wall | Exact docking at each action point |

> A passed replay is evidence, not proof. The trial in [[WI-05]] is the proof.
