# WI-07 · Check the map on all robots

**Purpose:** confirm that every robot uses the same map, and find the ones that do not.

Robots on different maps do not agree where the walls and stations are. One robot may drive well and another jump at the same place. A test robot left on a trial map, or a robot that missed a map push, shows up here.

**You need:** all robots in the list ([[WI-01]] B) and this PC on the robot network.

## Steps

1. In the left panel press **Check maps on all robots**.
2. Each robot is asked which map it uses now. This only reads; it takes a few seconds.
3. Read the table at the bottom:

| Column | Meaning |
|---|---|
| current map | The name of the map the robot is using. |
| checksum | The first 8 characters of the file's md5. Same checksum = same file, whatever the name. |
| conf, station | The robot's confidence and nearest station right now. |
| `<-- DIFFERENT MAP` | This robot's file is not the one most robots use. |
| `= NAME in this workspace` | You already have this exact file. |
| not reachable | The robot is switched off or not on this network. |

4. The line under the table says either "All robots use the same map content" or lists the different checksums and which robots have each.

## When robots differ

1. Tick **download the different ones** and press the button again. Each map you do not have yet is copied into `maps`.
2. Choose one as **Map** and the other as **Second map**, press **Compare**. Every difference is listed: stations, paths, direction changes, wall dots, feature lines.
3. Decide which file is right. Putting it on the robots is done in RoboShop or the fleet manager, not here.

> Two maps can have the same name and different content. Always compare the checksum, never the name.

## When to run it

- After a map rollout, to confirm every robot took the file.
- Before building a candidate, to know which file is really in use.
- When one robot misbehaves at a place where the others drive well.
