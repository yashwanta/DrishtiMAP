# KB-06 · Feature lines and the virtual-laser fault

## What a feature line is

A feature line is a straight segment drawn along a wall and marked as a reliable feature for localisation. A map can hold thousands. They are drawn in pink when the **Feature lines** layer is on.

## The fault

If a feature line lies on or right beside a path, the robot treats it as something solid in its way. Driving there it raises a **virtual-laser fault** and stops, although nothing is there on the floor.

In the reference trial one short line, 0.16 m long and 0.12 m from the middle of path LM514–LM515, stopped the robot for 20 seconds.

## How a line gets onto a path

- Walls are moved or rescanned and an old line stays behind where the wall used to be.
- A piece of map is moved and a line that belonged to walls that stayed is moved with it, or the other way round.
- Clutter scanned on a route was turned into a line.

## How the program guards against it

| Where | What it does |
|---|---|
| **Detect** | Marks every feature line within 0.30 m of the middle of a path as a fault, and within 0.45 m as a warning. |
| Check list of every candidate | Fails if a line is closer than 0.45 m to a path, unless it was already that close on the base map. |
| **Remove feature lines lying on paths** (Tools, section 4) | Removes every line the check reports. |
| **Delete line** (Edit tab) | Removes the one you click. |

## Removing one

1. Run **Detect (map file only)**. The line is highlighted in red with a ring.
2. Edit tab → **Start editing** → **Delete line** → click it.
3. Save as a candidate. The feature-line check must pass.

Removing a single short line does not affect localisation: the walls it was drawn on are still in the map.
