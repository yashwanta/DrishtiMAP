# WI-06 · Change a map by hand (Edit tab)

**Purpose:** make small, exact changes: remove a feature line, change a path's direction, erase scanned clutter, replace walls from another map, move a station.

**You need:** the map to change, shown as **Map**. For "Take walls", also a **Second map** to take them from.

## How editing works

1. Choose the **Map**, open the **Edit** tab and press **Start editing the selected Map**.
2. You work on a copy in memory. The file on disk is not touched.
3. Every edit is added to **Edits so far**. **Undo last** removes the last one; **Discard all** drops everything.
4. Type a **Candidate name** and press **Save as candidate and check**. The result is a new file in `candidates` with a report listing each edit and the full check list.

## Edits on one object

Pick a tool, then click on the map.

| Tool | What to do | Typical use |
|---|---|---|
| **Select** | Click a station, a path or a feature line. Its details and buttons appear under the tools. | Look before you change. |
| **Delete line** | Click a feature line. It is removed at once. | A line on a path that raises a virtual-laser fault. |
| **Move station** | Drag a station. Its paths and bin follow. | Docking is off by a known amount. |
| **Add station** | Click the place, give a name. Type and properties are copied from a station of the same kind. | Rare. The fleet scene needs it too. |
| **Add path** | Click the start station, then the end station. | Rare. The fleet scene needs it too. |

With **Select** on a path you can press **Drive forward (direction 0)** or **Drive backward (direction 1)**, set any other property such as `maxspeed`, or delete the path. The arrow on the selected path shows its direction of travel.

With **Select** on a station you can type an exact position and direction, switch **Ignore direction**, or delete it.

> Feature lines are only clickable while the **Feature lines** layer is on (boxes above the map).

## Edits on an area

Draw a **Region** or a **Box** above the map first, then use the buttons under "Inside the drawn Region or Box".

| Button | What it does | Typical use |
|---|---|---|
| **Erase walls** | Removes wall dots and reflection points inside. | A pallet or cart scanned into the map on a route. |
| **Delete feature lines** | Removes every feature line whose middle is inside. | Lines left behind after walls changed. |
| **Take walls from Second map** | *replace*: walls inside are swapped for the other map's. *add*: the other map's walls are added. | One map has clean walls here, the other does not. |
| **Move walls** | Turns and shifts only the wall dots inside. Stations, paths and lines stay. | A wall section scanned slightly off. |
| **paths inside … Set** | Sets one property on every path with both ends inside. | Same direction or speed for a whole aisle. |

To move walls **and** stations together as one piece, use **Build → Move a region** on the Tools tab ([[WI-03]]), not this.

## After saving

1. Read the report. The edited stations and paths are listed under "changed by hand": confirm each one.
2. The clearance checks still apply. A station moved toward a wall fails "no station is closer to a wall"; decide if that is intended.
3. Replay a recording through the new candidate ([[WI-04]] B).
4. Trial on one robot ([[WI-05]]).

## Example: the feature line at LM514–LM515

1. **Map** = the map with the line. **Detect (map file only)** marks it with a red diamond: `line on path LM515`.
2. Edit tab → **Start editing** → **Delete line** → click the marked line.
3. Name it, **Save as candidate and check**. The check "no feature line closer than 0.45 m to a path" now passes.

## Example: change a path from backward to forward

1. Edit tab → **Start editing** → **Select** → click the path.
2. Press **Drive forward (direction 0)**. Repeat for each path of the stretch, or draw a Region around the stretch and use **paths inside: direction = 0, Set**.
3. Save. The report lists the paths under "changed by hand".
