          Output
          Pick a map on the left to see it. Pick a recording and a map, then use Tools on the right.

          Example: Recording = a drive you recorded, such as amr06_loop_nov13; Map = the map to test, such as SPRAMRMAP_v5c; Second map empty; Samples empty = the whole drive. Samples 40 to 262 = only that part of the drive. Lists empty on a new PC? Nothing comes with the program: get the map with map and a recording with rec on a robot in the left panel (steps below), or copy a recording folder from another PC into drives in the workspace folder.

          0 · Detect

          Lists everything that looks wrong and marks it on the map. With a Recording it also finds jumps and low wall match.

          Example: with a recording, a red circle JUMP 1.36 m near LM520 = robots jump there. Map file only, a red diamond line on path LM515 = a feature line lies in the robot's way.

          How to get a recording (example: AMR-03, east loop)
          1. This PC must be on the robot network.
          2. Left panel, Robots: point at AMR-03 and press rec. Robot not listed? Press + and type AMR-03 10.0.0.27 (name, space, robot IP).
          3. Recording name: amr03_east_loop. Stop after: 15 minutes. Press Start recording.
          4. Drive the robot through the trouble spot: start 15 m before it, end 15 m past it.
          5. Click the red REC badge at the top to stop.
          6. Choose it in Recording above, choose the Map, press Detect with Recording.
          It only reads from the robot. Keep this window open while it records. More: Help, WI-01.

          1 · What the robot reported

          Stations, confidence and jumps from the recording itself.

          Example: choose a Recording and press the button. You get each station passed with its confidence, and every place the robot itself reported a jump or lost position. No map is needed.

          LiDAR · what each scanner sees

          One scan at a time on the map, each scanner in its own colour, with the height of its scan plane. Arrow keys step; Shift = 10.

          Example: type 120 and press Show sample to see what the scanners saw at sample 120; press ▶ to step along the drive. Or choose AMR-03 and press Live from robot. Springfield scanners sit 0.194 m (front) and 0.197 m (rear) above the floor, so anything lower is not seen.

          2 · Test a map with the recording

          Lays the recorded lasers on Map. A step of 0.5 m or more is where a robot jumps. Works for maps never loaded on a robot.

          Example: Map = a candidate that was never on a robot. Replay: no step of 0.5 m or more = good; a step of 1.36 m at LM520 = robots would jump there. Rigid track: about 0.1 m rms = the map agrees with the lasers. Find rigid pieces: two long pieces with a turn of about 2° between them = one piece is attached at the wrong angle.

          3 · Measure a wrongly attached piece

          Sample ranges come from “Find rigid pieces”. Piece is on Map; the reference is on Second map (or Map if empty).

          Example: Piece samples 40-262, Reference samples 1-30, 310-370, stations LM443 LM521, then Measure turn. The result reads like turn 2.07 deg, spread +-0.17, and th, tx, ty are filled into section 4 for you. Show drift: a difference that grows steadily along the route = a piece attached at an angle.

          4 · Build a candidate

          Writes a new file to candidates. Never loaded on a robot by this app. Base = Map.

          Example: Candidate name SPRAMRMAP_v6. The new file goes to candidates; the base map is not changed.

          Move a region as one piece

          Example: after Measure turn, press Region above the map, click corners around the whole misplaced piece (Springfield: the east loop), double-click to finish, then press Build. Walls, stations and paths inside move together.

          Take walls in a box from Second map

          Example: Map has messy walls at one dock; Second map = an older map with clean walls there. Press Box above the map, drag over the dock, then press Build.

          Remove feature lines lying on paths

          Removes from Map every line the check reports against Second map.

          Example: the check fails with a line 0.12 m from path LM514-LM515. Press Build: the candidate is the same map without that line.

          5 · Check and compare

          Example: Map = SPRAMRMAP_v5c, Second map = SPRAMRMAP_v5. Check: every line must say PASS. Compare: lists everything that differs between the two. Map details: what is in the Map file.

          Change a map by hand: remove feature lines, erase or replace walls, change a path's direction or speed, move, add or delete stations and paths. You work on a copy; saving writes a new candidate file with a check report. Nothing goes to a robot.

          Example: remove the feature line at LM514-LM515. Choose the Map on the Tools tab, press Start editing, press Delete line, click the line, type a name, press Save as candidate and check.

          Example: Select, click a path, then Drive forward (direction 0). Move station, drag LM520: its paths follow. Add path: click the start station, then the end station.

          Inside the drawn Region or Box

          Draw with the Region or Box button above the map first.

          Example: a pallet was scanned into an aisle: drag a Box over it, press Erase walls. A wall section is 1° off: turn 1 about x 36.2 y 35.3, shift 0 0, Move walls. A whole aisle forward: draw a Region, paths inside direction = 0, Set.
